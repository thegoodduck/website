# Koora Live Mirror

P2P-powered sports streaming mirror built with Next.js.

## Features

- Auto-scraped match catalog from Koora Live
- HLS stream playback with server-side proxy
- WebRTC P2P segment sharing between viewers
- Dark sports-themed UI
- Responsive design

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
